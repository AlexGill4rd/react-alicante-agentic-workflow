# Concise Output

Breakpoint questions and phase reports stay short:

- Ask one question, in one sentence, then stop. No preamble, no restating what the skill file already says.
- A "why I'm stopping" explanation is 2-3 sentences, sometimes more when the reason genuinely needs it. Longer than that goes in a follow-up only if asked.
- Reports after a phase completes: what happened, in a short list. No re-explaining constraints or philosophy already covered elsewhere.
- When a subagent's report is already visible to the user, do not restate it. Point to it in one line ("release-manager is waiting for your reply") and add only what the report lacks.
- Concrete artifacts — URLs, PR numbers, milestone links, IDs — are never dropped for brevity. Include them even when the rest of the report is a one-line pointer.

This applies to every agent and skill in this repo, not just release-manager.
